스토리보드 생성기

캐릭터와 이야기를 설정하고,
영상으로 제작할 수 있는 콘티와 프롬프트를 만듭니다.

어떤 장면을 만들고 싶은지에서 출발해, 생성 결과를 직접 확인하며 연출과 제작 흐름을 개선하고 있습니다.

영상 프롬프트

개발 방식
직접 기획·사용 테스트, AI 코딩 도구와 구현 협업
소스 코드와 공개 베타
사용 예시앱 화면개발 과정구현과 검증

설정에서 완성 영상까지

하나의 작업을 처음부터 끝까지 따라가는 사용 예시.

실제 제작 예시 준비 중
  1. 01

    내가 설정한 것

    캐릭터의 성격과 말투, 관계, 장소와 상황, 원하는 이야기 방향.

    캐릭터 페르소나상황과 상호작용목표 길이와 연출

    대표 작업의 입력 원문을 여기에 공개할 예정입니다.

  2. 02

    생성기가 만든 것

    대사와 행동, 카메라 구도가 담긴 콘티와 모델별 영상 프롬프트.

    컷별 콘티15초 단위 제작 계획최종 영상 프롬프트

    생성 결과와 직접 수정한 부분을 구분해 기록할 예정입니다.

  3. 03

    그 콘티로 만든 애니메이션

    콘티와 프롬프트를 외부 영상 생성 모델에 사용해 제작한 결과.

    제작 후 공개

    완성 영상과 대응하는 컷을 함께 비교할 예정입니다.

대표 사례의 콘티와 완성 영상은 아직 준비 중입니다. 아래 화면은 기존 공개 UI 소개이며, 위 제작 예시의 결과물이 아닙니다.

현재 구현한 작업 공간

입력, 편집, 변환을 한 프로그램에서 이어갑니다.

캐릭터를 설정하고 컷을 편집합니다

성격과 말투를 입력하고, 생성된 대사·행동·카메라 연출을 컷별로 확인합니다. 유지하고 싶은 컷은 고정해 재생성에서 보존합니다.

현재 캐릭터 1~5명 지원.
공개 캡처는 기존 2인 예시입니다.

콘티를 영상 제작 단위로 변환합니다

30초 콘티를 15초씩 나누고, MiniMax H3 또는 Seedance 2.0에 사용할 프롬프트를 만듭니다. 지시문은 영어로, 대사는 원문과 화자를 유지해 조립합니다.

캐릭터별 여러 참조 이미지 지정.
TXT·JSON·참조 이미지 ZIP 내보내기.

사용하면서 바꾼 것들

기능을 만드는 데서 시작해, 실제 제작에서 드러난 문제를 수정했습니다.

설정 → 생성 → 제작 → 피드백

오류를 피하는 것만큼, 원하는 장면을 만들 수 있는지가 중요했습니다.

구현과 검증 범위 보기
01페르소나를 컷별 이야기로기본 제작

출발점 캐릭터의 성격과 사용자가 원하는 상호작용을 대사·행동·장면으로 만들고 싶었습니다.

구현 페르소나와 장면 설정을 구조화하고 컷별 편집·고정·재생성을 연결했습니다. 인물과 소품의 시작·종료 상태도 함께 기록합니다.

02다시 찾아 작업할 수 있는 도구로작업 환경

문제 생성한 콘티를 관리하기 어렵고, 필수 입력이나 API 설정 오류가 작업을 막았습니다.

개선 필수 항목 표시, 웹 API 설정, 보관함 검색·미리보기·휴지통·복원과 한·영·일 언어 설정을 구성했습니다. 캐릭터는 고정된 2명에서 1~5명으로 확장했습니다.

03AI가 대사를 다시 쓰지 않도록출력 보존

문제 영상 프롬프트 변환에서 원본 대사가 누락·변경되거나, 공유 경계 상태가 어긋났습니다.

개선 AI는 연출 구성 요소를 반환하고 프로그램이 원문 대사와 화자를 조립하도록 분리했습니다. 공통 경계 상태는 양쪽 구간에 같은 값으로 삽입하며 형식 오류의 교정 횟수도 제한합니다.

0430초 이야기를 15초씩 제작하기클립 연결

문제 클립 하나를 전체 이야기로 평가하거나, 분할 지점에서 동작과 카메라가 다시 시작되는 문제가 있었습니다.

개선 선택 구간의 계획과 전체 이야기의 맥락을 구분하고 원본 컷 오프셋·대사 배치·공유 카메라를 보존했습니다. 소수점 클립은 마지막 화면 유지로 공식 프로필의 정수 길이에 맞춥니다.

05모델마다 다른 문법과 제작 재료가이드

문제 같은 프롬프트를 모든 모델에 쓰거나 참조 이미지를 모호하게 부르면 의도한 제작 재료가 전달되지 않았습니다.

개선 공식 자료를 바탕으로 모델별 가이드와 시스템 프롬프트를 분리했습니다. MiniMax 참조는 <Picture N>으로 정규화하고, 캐릭터별 여러 이미지와 첨부 순서를 관리합니다. 영어 지시문과 원문 대사를 구분해 TXT로 내보냅니다.

06캐릭터다운 말투와 일본어 대사대사 품질

문제 성별·연령·관계에 맞는 말투와 자연스러운 일본어 문법을 직접 고쳐야 했습니다.

개선 선택형 성별·연령과 인칭·존댓말·대사 예시를 반영하고 일본어 대사 전용 교정을 추가했습니다. 고정 컷과 지정한 원문은 제외합니다. 최신 로컬 구현은 긴 교정 목록도 나누어 처리합니다.

07구도의 다양성에서 행동의 인과까지로컬 개선

피드백 일반적인 샷 교대보다 일본 2D 애니메이션에 어울리는 연출이 필요했습니다. 이후에는 정차 없이 지하철에서 내리는 장면처럼 행동의 선행 조건이 빠진 문제도 발견했습니다.

개선 대사의 의도와 상대의 반응에 따라 시선·옆얼굴·손동작·여백·깊이를 선택하도록 지침을 보강했습니다. 모든 주요 행동은 필요한 상태·접근·소지·지식·동기·시간을 확인하고 결과가 다음 컷에 이어지도록 공통 인과 지침을 연결했습니다.

구분 사용자는 구도 개선 후 자연스러운 연출을 확인했습니다. 일반화한 인과 지침의 실제 영상 재검증은 아직입니다.

08많은 컷을 하나의 긴 응답에 담지 않기로컬 개선

문제 최대 컷 수를 60개로 늘린 뒤에도 큰 응답이 제한에 걸렸습니다. 스트리밍 이벤트의 부가 데이터까지 생성 내용의 크기로 계산하고 있었습니다.

개선 13컷 이상은 전체 흐름을 먼저 설계하고 최대 6컷씩 상세화합니다. 이전 컷과 고정 컷의 맥락을 전달하고 모든 묶음을 검증한 뒤 통합합니다. 스트리밍 전송량과 실제 생성 내용의 제한을 구분하고 가져오기·저장 용량도 확대했습니다.

남은 과제 호출 수에 따라 시간·비용이 증가합니다. 중간 실패 뒤 이어서 생성하는 체크포인트는 아직 없으며 실제 유료 AI의 대량 생성 검증도 남아 있습니다.
