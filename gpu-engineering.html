실기 검증 환경
1
  1. C · UEFI

    RTX 3090 환경 포팅

    상위 RTX 3080 포트를 RTX 3090 24 GiB·AMD 내장그래픽 환경에 맞추고, 장치 식별과 메모리·출력 조건을 검사합니다.

  2. PCI · DMA · FLR

    실행과 정리 조건

    소유권과 단계별 쓰기 조건, 자원 수명과 정리 상태를 확인합니다. 실패한 실행을 성공으로 넘기지 않는 경계를 유지합니다.

  3. LLVM · PE/COFF · SHA-256

    빌드와 소스 추적

    기록된 clang 20.1.8 빌드와 성공 EFI의 일치를 확인하고, 상위 코어와 헤더를 포함한 대응 소스 57개의 해시를 검증했습니다.

  4. CUDA · cuBLAS · GEMM

    Windows 연산 측정

    같은 실행 파일과 드라이버로 부팅 경로별 결과를 비교합니다. UEFI 성공, Windows 진입, 연산 성능을 별도의 증거로 남겼습니다.

  5. Python · USB PACKAGE

    검증하는 패키징 도구

    펌웨어와 소스의 크기·해시를 검사하고 새 로컬 폴더만 생성합니다. 기존 대상과 경로 이탈은 거부하며 디스크를 포맷하지 않습니다.

  6. DOCS · INVENTORY

    공개 안내와 호환성 조사

    영문·한국어 적용 문서와 읽기 전용 환경 수집기를 제공합니다. 수집 결과는 지원 조사에 사용하며 언락 허가로 바꾸지 않습니다.

상위 GPL 코어와 포트의 기여를 보존한 확장 작업입니다. 아래에서 본인의 포팅·진단·측정·문서화 범위를 구분합니다.

01 / 측정 결과

성공 메시지가 아닌,
실제 연산으로 확인.

같은 CUDA 12.6·cuBLAS 실행 파일의 4096 × 4096 GEMM을 비교했습니다. UEFI 성공과 실제 연산 결과를 별도로 기록했습니다.

담당한 작업
RTX 3090 환경 포팅 · 부팅 인계 진단 · 동일 조건 벤치마크 · 공개 문서화

Codex와 협업해 구현·검증했습니다. 원천 코어는 Zagitta/gpu-unlock이며, rough2515-hub의 RTX 3080 UEFI 포트를 바탕으로 확장했습니다.

02 / 문제와 진단

무엇을 바꿨는가보다,
어디서 상태가 달라졌는가.

언락 상태와 Windows 인계를 구분하고, ASUS Boot Override로 리셋 없이 진입하는 경로를 확인했습니다.

이전 부팅 경로

Save Changes & Reset

  2. 펌웨어에서 리셋
  3. Windows 진입 후 측정

FP16 70.55 · BF16 70.53 TFLOPS

리셋 없는 Windows 인계

Boot Override

  1. UEFI 언락 성공
  2. 리셋 없이 Boot Manager로
  3. Windows 진입 후 측정

FP16 125.91 · BF16 128.70 TFLOPS

위 경로는 사용자가 보고한 실제 부팅 절차입니다. 측정 결과는 리셋에 따른 상태 소실 가설을 뒷받침하지만, 다른 모든 원인을 배제하는 실험은 아닙니다.

03 / 구현과 검증

실행 조건부터 정리까지,
검증할 수 있는 구조로.

상위 포트를 기반으로 카드·출력 환경에 맞는 검사와 실험 프로필을 구성하고, 실행 결과를 소스·테스트·로그에 연결했습니다.

IDENTITY

실행 대상과 상태 검사

PCI 식별자·PROM 해시·메모리 배치·화면 출력 경로를 확인합니다. 검증하지 않은 환경에서는 실행을 허용하지 않습니다.

TRANSACTION

단계와 자원 수명 관리

초기 selector를 고정하고 쓰기 단계를 제한합니다. PCI 소유권·DMA·FLR 정리 상태를 확인하며, 불완전한 정리는 성공으로 처리하지 않습니다.

PROVENANCE

소스와 실행물 연결

공개 EFI의 해시와 대응 소스 57개의 해시를 대조했습니다. 성공 실행 로그와 Windows 측정 자료를 분리해 공개했습니다.

14Python 도구 테스트 통과
10기록된 host mock 검사 그룹

Host mock 기록은 하드웨어 접근 없는 검사입니다. 소프트웨어 검사 통과와 실제 GPU 검증을 구분합니다.

04 / 공개와 확장

개인 실험에서,
다른 사람이 읽을 수 있는 기록으로.

  1. 01

    적용 절차 문서화

    영문·한국어로 펌웨어 준비, USB 구성, 부팅 인계, 성능 비교와 실패 대응을 정리했습니다.

  2. 02

    읽기 전용 환경 수집

    언락 없이 모델·버전 정보를 수집합니다. 고유 식별 필드를 제외하고, 보고서를 실행 허가로 사용하지 않습니다.

  3. 03

    근거에 따른 지원 확대

    장치 탐색과 GPU 정책을 분리하는 설계를 공개했습니다. 새 EFI 프로필은 별도의 코드 검토와 실기 검증을 거쳐야 합니다.

실제로 확인한 범위

RTX 3090 24 GiB · ASUS TUF B650M-PLUS WIFI · Ryzen 7 7800X3D · AMD iGPU · Windows 11 · NVIDIA 617.14

아직 검증하지 않은 것

다른 GPU·메인보드, 장시간 안정성, ComfyUI·게임의 실제 속도 향상은 미검증입니다. 범용화는 진단·제보 기반까지 구현했으며 EFI 지원 확대는 후속 과제입니다.

진단 → 가설 → 동일 조건 측정 → 근거와 한계 공개. 제작 환경의 문제를 재현 가능한 엔지니어링 기록으로 남겼습니다.
