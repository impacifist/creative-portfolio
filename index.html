한국어 연출 지시의 해석과 양자화 환경에서의 응답성을 직접 확인하며 선택했습니다. 이미지 속 특징을 설명하는 능력을 영상 제작 지시 작성에 활용합니다.

  1. 이미지에서 시각적 기준 추출

    캐릭터의 외형·화풍·현재 자세를 읽고, 참조 이미지가 담당할 역할을 구분합니다.

  2. 사용자의 연출 의도 결합

    한국어 지시에서 동작·길이·카메라·금지 조건을 정리합니다. 유지할 외형과 바꿀 의상·배경을 나눕니다.

  3. H3 형식으로 구조화

    시스템 프롬프트로 참조 번호, 숏과 시간, 음향 규칙을 지정하고 6개 섹션의 영어 프롬프트를 작성하도록 지시합니다.

변환 예시 참조 외형은 유지하고, 의상과 동작은 요청에 맞게

02

데이터셋 툴

LoRA 관리와 프롬프트 준비를
ComfyUI 안에서 한 번에.

  1. 목록·설치 상태 확인
  2. 필요한 LoRA 복사
  3. 캡션으로 프롬프트 준비

Sync로 LoRA를 ComfyUI 폴더에 복사하고, Analyze로 캡션의 공통 특징을 추출해 프롬프트를 클립보드로 가져옵니다.

Python과 Codex로 개발했습니다. 모델 설치 상태 확인과 캡션 기반 프롬프트 구성을 연결하고, 로컬에서 직접 사용하며 개선했습니다.
