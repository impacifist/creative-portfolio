01

AI 영상 스토리보드 생성기

캐릭터의 성격을 콘티로,
콘티를 영상 프롬프트로.

  1. 캐릭터·상황 설정
  2. 컷별 콘티 편집
  3. 영상 프롬프트 변환

두 인물의 성격과 말투, 관계와 상황을 입력해 대사·행동·카메라 연출을 담은 콘티를 만드는 로컬 웹앱입니다. 컷을 편집하고 고정하거나, 저장한 콘티를 검색해 다시 작업할 수 있습니다.

Seedance 2.0·MiniMax H3 가이드에 맞춰 변환하며, 30초 콘티는 15초 클립 두 개로 나눕니다. 대사와 화자는 프로그램이 원문 그대로 조립하고 영상 지시문은 영어로 구성합니다.

Python과 JavaScript로 구현했습니다. OpenAI·호환 API, Claude, Ollama를 연결하며 한국어·영어·일본어 UI를 지원합니다. 캐릭터별 여러 참조 이미지를 지정하고 프롬프트 TXT·JSON·이미지 ZIP으로 내보낼 수 있습니다.

출력 검증과 현재 범위

시간·컷 순서·대사 보존·공유 경계 상태를 검사하고, 구조화된 출력이 검증에 실패하면 최대 한 번 추가 호출로 교정합니다. 실제 영상과 콘티 이미지를 생성하는 기능은 포함하지 않습니다.

공개 베타이며 자동 검증은 모의 AI로 수행했습니다. 실제 유료 모델의 생성 품질과 영상의 연속성을 보장하지 않습니다.

04

Prompt Selector

자주 쓰는 프롬프트를 저장하고,
워크플로우 안에서 골라 씁니다.

  1. 이름·태그로 저장
  2. 검색·정렬해서 선택
  3. 텍스트 입력에 연결

메모장이나 이전 워크플로우에서 프롬프트를 찾아 복사하는 반복 작업을 줄이기 위해 만든 ComfyUI 커스텀 노드입니다. 카메라, 조명, 스타일별 문구를 모아 두고 필요한 입력에 연결합니다.

검색·태그·즐겨찾기로 문구를 찾고, 원본을 남겨 새 버전을 저장할 수 있습니다. 같은 워크플로우에서는 목록을 공유하면서 노드마다 다른 문구를 선택합니다.

목록은 워크플로우에 저장하며 JSON 파일로 옮길 수 있습니다. Python과 JavaScript로 구현하고 Codex와 함께 개선했습니다. 별도 생성 모델 없이 사용하는 MIT 공개 도구입니다.

영상의 필요한 구간만 골라 원본과 추출 결과를 비교합니다. 여러 전처리 도구를 오가는 과정을 ComfyUI 노드 하나로 모았습니다.

  1. Pose · 자세

    인물의 자세와 움직임을 추출합니다.

  2. Depth · 깊이

    장면의 깊이와 사물 배치를 읽습니다.

  3. Canny · 윤곽

    윤곽선과 장면 구조를 추출합니다.

  1. 구간 선택
  2. 추출
  3. 원본과 비교
  4. 영상 생성에 연결

한 프레임만 먼저 시험하고, 비교선을 움직이며 결과를 확인합니다. 자주 쓰는 설정은 저장할 수 있고 한국어·영어를 지원합니다.

실제 사용 화면 · 한국어 UI 보기
구현과 사용 범위

ComfyUI의 SDPose·Depth Anything 3·Canny를 활용하고, Python과 JavaScript로 추출·비교·설정 저장 UI를 구성했습니다. 결과는 이미지 묶음 또는 무음 영상으로 전달하며, 비교 조작은 추론을 다시 실행하지 않습니다.

MiniMax H3 Fun ControlNet 등에 참조를 전달하며 영상 생성 자체는 수행하지 않습니다. Pose는 단일 인물용이고 Depth에는 프레임 사이의 깜빡임이 생길 수 있습니다.

패키지는 MIT 라이선스입니다. 기반 모델·ComfyUI·원본 영상의 권리는 각 권리자에게 있습니다.

이렇게 사용합니다

  1. 연출 준비

    참조 이미지와 연출 지시로 프롬프트를 준비합니다.

  2. 클립 생성

    앞 장면의 이미지와 움직임 정보를 다음 생성에 전달합니다.

  3. 장면 연결

    겹친 구간을 덜어내고 영상과 소리를 연결합니다.

  4. 마무리

    움직임과 화질을 다듬고 완성 영상을 저장합니다.

제가 구성한 부분

Prompt Selector와 로컬 VLM을 기존 생성·후처리 노드에 연결해, 연출 준비부터 영상 저장까지 하나의 흐름으로 구성했습니다.

실제 연결을 기능별로 묶은 공개용 구조도입니다. 개인 입력과 원본 파일은 포함하지 않았으며, 기반 모델과 외부 노드는 각 제작자의 작업입니다.
